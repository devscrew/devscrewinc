# Senior Frontend Development

Use this skill whenever working on React/Vite.

Workflow

1. Inspect existing implementation.
2. Understand data flow.
3. Find root cause.
4. Produce implementation plan.
5. Implement.
6. Test.
7. Refactor if needed.

Checklist

□ No duplicated logic
□ Type-safe
□ Responsive
□ Accessible
□ No unnecessary rerenders
□ Clean imports
□ Consistent naming
□ Minimal bundle impact

When reviewing code:

- Suggest better abstractions.
- Look for race conditions.
- Detect memory leaks.
- Improve readability.
- Remove unnecessary complexity.
